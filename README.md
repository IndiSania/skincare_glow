# GlowCare — React Skincare Store

Website skincare demo berbasis React JS + Vite.

## Fitur
- Landing page skincare dengan desain responsif
- Katalog produk skincare
- Pencarian produk
- Filter kategori
- Favorit produk
- Keranjang belanja dengan tambah/kurangi kuantitas dan subtotal
- Bagian panduan rutinitas skincare
- Toast notifikasi
- Tampilan mobile dan desktop

> Catatan: ini adalah proyek front-end demo. Checkout belum terhubung ke backend atau pembayaran sungguhan. Data produk masih tersimpan di file `src/main.jsx`.

## Cara menjalankan
Pastikan Node.js sudah terpasang.

1. Ekstrak ZIP.
2. Buka folder `glowcare_skincare_react` di VS Code.
3. Buka terminal di folder tersebut.
4. Jalankan:

```bash
npm install
npm run dev
```

5. Buka alamat lokal yang ditampilkan Vite, biasanya `http://localhost:5173`.
